# Coach App portfolio visuals

AI-generated portfolio mockups based on the project's forest-green, ivory,
and pale-lime design. These are presentation concepts, not screenshots or
proof of device testing. People and exercise scenes are synthetic. Browser
addresses, illustrative screen details, and displayed counts are placeholders.
The phone images represent the responsive web app, not a released native app.

- `coach-app-hero.png`: project cover with laptop and phone.
